# Employee_inf
This project follows an end-to-end data analysis workflow. The dataset was initially taken in Excel and then converted into SQL for better data handling and querying. SQL was used to clean the data and extract useful insights. After that, the processed data was imported into Power BI to build an interactive dashboard.

The dashboard includes multiple pages such as Overview, Salary Analysis, Performance Analysis, Location Analysis, and Trends Analysis. Different DAX measures and visualizations were used to analyze employee data and generate meaningful business insights.
